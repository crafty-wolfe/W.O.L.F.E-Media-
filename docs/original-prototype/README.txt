W.O.L.F.E MEDIA PROTOTYPE v1

Extract this folder into:
D:\W\.O.L.F.E\Media Center

Run either:
- Launch WOLFE Main.bat
- Launch WOLFE Lite.bat

Controls:
Arrow keys  navigate
Enter       select
Escape      back / home
C           simulate driveway camera alert
I           simulate the IPTV 2-connection warning

Included:
- Main and Lite layouts
- Who's Watching: Mike, Amy, Alfie, Brooke, Elsie-Joan, Visitors
- Per-profile local state using browser localStorage
- Continue Watching and recommendation demo rows
- On Demand, Movies, Series, Kids, Cameras, Home Control placeholder, Apps
- Netflix, Prime Video, Disney+, YouTube and IPTV tiles
- Simulated 2-connection IPTV manager
- Simulated camera popup
- Full-screen TV-friendly navigation

This is a UI prototype only. It contains no IPTV credentials, copyrighted media,
Home Assistant credentials, camera credentials or streaming passwords.
